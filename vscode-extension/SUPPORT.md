# TAcroMan Support

For bug reports, feature requests, and reproducible problems, please use the
GitHub issue tracker:

https://github.com/TAWilts/TexAcronymManager/issues

When reporting a VS Code extension issue, please include:

- TAcroMan VS Code extension version;
- Visual Studio Code version;
- operating system;
- the relevant TAcroMan database structure or a minimal example, if possible;
- a short LaTeX example that reproduces the behavior.

For security-sensitive reports, avoid posting secrets, private documents, or
confidential data in a public issue.
